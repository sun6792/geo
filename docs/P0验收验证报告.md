## 二、发现的 Bug 与修复记录

### Bug #1: `roles.py` set_role_permissions 参数解析错误 [已修复]
- **文件**: `backend/app/api/v1/roles.py:69`
- **严重级别**: HIGH — 功能错误
- **问题**: `permission_ids: list[uuid.UUID]` 未使用 Pydantic 模型包装，FastAPI 会将其解析为查询参数而非 JSON Body
- **修复**: 添加 `= Body(..., embed=True)`，使端点接受标准 JSON Body `{"permission_ids": [...]}`

### Bug #2: `publish.py` publish_now 可变默认参数 [已修复]
- **文件**: `backend/app/api/v1/publish.py:98`
- **严重级别**: MEDIUM — Python 反模式
- **问题**: `body: dict = {}` 可变默认参数会导致请求间状态泄露
- **修复**: 改为 `body: dict | None = None`，使用时 `(body or {}).get(...)`

### Bug #3: `auth_service.py` 失败登录审计外键冲突 [已修复]
- **文件**: `backend/app/services/auth_service.py:40`
- **严重级别**: HIGH — 数据库写入失败
- **问题**: 用户不存在时 `customer_id` 设为零 UUID，但 LoginAudit 有 FK 约束到 customers 表
- **修复**: 将 `LoginAudit.customer_id` 改为 nullable (ORM + SQL 同步修改)，失败登录时 `customer_id=None`

### Bug #4: 缺失 `logo.svg` [已修复]
- **文件**: `frontend/src/layout/Sidebar.vue:4`
- **严重级别**: LOW — UI 显示问题
- **问题**: 引用的 `@/assets/images/logo.svg` 不存在
- **修复**: 创建 SVG logo 文件

### Bug #5: 缺失 `/account/profile` 路由 [已修复]
- **文件**: `frontend/src/layout/Navbar.vue:23`
- **严重级别**: LOW — 导航 404
- **问题**: Navbar 中"个人设置"链接到不存在的路由
- **修复**: 添加路由 + 创建 Profile.vue 页面（含修改密码功能）

### Bug #6: `__import__("datetime").timedelta` 反模式 [已修复]
- **文件**: `auth_service.py` (2 处) + `review_service.py` (1 处)
- **严重级别**: LOW — 代码异味
- **修复**: 统一使用 `from datetime import timedelta` 标准导入

### Bug #7: `login_audit.id` / `kb_changelog.id` BIGSERIAL vs Integer [已修复]
- **文件**: `account.py`, `knowledge_base.py`
- **严重级别**: MEDIUM — ORM 类型不一致
- **问题**: SQL 使用 BIGSERIAL(64位)，ORM 默认 Integer(32位)
- **修复**: ORM 添加 `BigInteger` 导入和列类型

### Bug #8: 种子数据密码哈希无效 [已修复]
- **文件**: `db/init/02-seed.sql`
- **严重级别**: CRITICAL — 无法登录
- **问题**: 硬编码的 bcrypt 哈希是占位符，不是 "admin123" 的有效哈希
- **修复**: 通过 `bcrypt.hashpw()` 生成正确哈希并替换

## 三、已知限制（非 Bug，不影响 P0 可用性）

1. **Python 3.10+ 要求**: 本地开发环境需 Python 3.10+ (Docker 容器中使用 Python 3.11)
2. **ORM UniqueConstraint 缺失**: 14 个复合唯一约束在 SQL 中存在但 ORM 未声明；由于使用 SQL init 脚本建表，DB 层面约束完整生效
3. **前端部分页面为 stub**: 知识库/内容/审核/发布页面的详细实现将在后续完善
4. **LLM API 密钥**: 需要配置有效的 OpenAI/Anthropic API 密钥才能使用 AI 生成功能
5. **Chroma 集成**: 向量嵌入管道需要启动 Chroma 服务后可用

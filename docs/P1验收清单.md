## 二、智能体1 — 全域探测采集

### 后端验证
- [ ] `POST /api/v1/detection/tasks` — 创建探测任务（含关键词、目标模型、竞品）
- [ ] `GET /api/v1/detection/tasks` — 分页查询任务列表
- [ ] `PATCH /api/v1/detection/tasks/:id` — 更新任务配置
- [ ] `POST /api/v1/detection/tasks/:id/run` — 手动触发探测执行
- [ ] `GET /api/v1/detection/results` — 查询探测结果（支持按任务/模型筛选）
- [ ] `GET /api/v1/detection/summary` — 获取各模型汇总数据
- [ ] `POST /api/v1/detection/competitors` — 添加竞品
- [ ] `GET /api/v1/detection/competitors` — 竞品列表
- [ ] `GET /api/v1/detection/source-verifications` — 信源校验清单
- [ ] `GET /api/v1/detection/sentiment` — 舆情数据
- [ ] `GET /api/v1/detection/sentiment/summary` — 舆情汇总

### 前端验证
- [ ] 探测任务管理页：任务CRUD、模型多选、关键词配置、调度设置
- [ ] 探测结果概览表：按模型展示品牌提及率、平均排名
- [ ] 竞品管理：添加竞品功能

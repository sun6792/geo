# GEO AI 智能体运营系统 — 服务器部署手册

## 一、环境要求

| 组件 | 最低版本 | 说明 |
|------|---------|------|
| Docker | 24.0+ | 容器运行时 |
| Docker Compose | 2.20+ | 服务编排 |
| 操作系统 | Linux (Ubuntu 20.04+/CentOS 8+) | 推荐 Ubuntu 22.04 LTS |
| CPU | 4 核+ | 推荐 8 核 |
| 内存 | 8 GB+ | 推荐 16 GB |
| 磁盘 | 50 GB+ | SSD 优先 |

## 二、快速部署（5 分钟）

### 1. 上传项目文件

```bash
# 将整个项目目录上传至服务器
scp -r ./geoai-platform user@server:/opt/
cd /opt/geoai-platform
```

### 2. 配置环境变量

```bash
# 复制环境变量模板
cp backend/.env.example backend/.env

# 编辑以下关键配置（必须修改）
vi backend/.env
```

**必须修改的配置项：**
```ini
# 数据库密码（生产环境必须使用强密码）
DATABASE_URL=postgresql+asyncpg://geoai:YOUR_STRONG_PASSWORD@postgres:5432/geoai_platform

# JWT 密钥（生成随机字符串替换）
JWT_SECRET=YOUR_RANDOM_SECRET_KEY_AT_LEAST_32_CHARS

# LLM API 密钥（至少配置一个）
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-your-actual-api-key
# 或
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-your-actual-api-key
```

### 3. 创建 .env 文件（Docker Compose 用）

```bash
# 在项目根目录创建 .env
cat > .env << 'EOF'
DB_PASSWORD=YOUR_STRONG_PASSWORD
JWT_SECRET=YOUR_RANDOM_SECRET_KEY
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-your-key
LOG_LEVEL=INFO
EOF
```

### 4. 一键启动

```bash
# 构建并启动所有服务
docker compose up -d --build

# 查看服务状态
docker compose ps

# 查看日志
docker compose logs -f
```

### 5. 验证部署

```bash
# 检查健康状态
curl http://localhost:8000/api/health

# 访问系统
# 浏览器打开: http://<服务器IP>
# 默认管理员: admin@geoai.com / admin123
```

## 三、服务端口说明

| 服务 | 内部端口 | 外部端口 | 说明 |
|------|---------|---------|------|
| Nginx | 80 | 80 | 反向代理入口 |
| Frontend | 80 | 8080 | Vue3 前端（开发模式） |
| Backend API | 8000 | — | FastAPI（仅内部） |
| PostgreSQL | 5432 | 127.0.0.1:5432 | 数据库 |
| Chroma | 8001 | 127.0.0.1:8001 | 向量数据库 |

## 四、日常运维

### 查看服务日志

```bash
# 所有服务
docker compose logs -f

# 指定服务
docker compose logs -f backend
docker compose logs -f postgres
```

### 重启服务

```bash
# 重启单个服务
docker compose restart backend

# 重启所有服务
docker compose restart
```

### 更新应用

```bash
# 拉取最新代码后重新构建
git pull
docker compose up -d --build
```

## 五、数据备份与恢复

### 备份数据库

```bash
# 备份 PostgreSQL
docker compose exec postgres pg_dump -U geoai geoai_platform > backup_$(date +%Y%m%d).sql

# 备份上传文件
tar -czf uploads_backup_$(date +%Y%m%d).tar.gz ./uploads/

# 备份 Chroma 数据
tar -czf chroma_backup_$(date +%Y%m%d).tar.gz ./chroma_data/
```

### 恢复数据库

```bash
# 恢复 PostgreSQL
docker compose exec -T postgres psql -U geoai geoai_platform < backup_20260701.sql
```

### 自动备份脚本

```bash
# 创建 /opt/geoai-platform/backup.sh
cat > backup.sh << 'SCRIPT'
#!/bin/bash
BACKUP_DIR="/opt/backups/geoai"
mkdir -p $BACKUP_DIR
DATE=$(date +%Y%m%d_%H%M)
cd /opt/geoai-platform
docker compose exec -T postgres pg_dump -U geoai geoai_platform > $BACKUP_DIR/db_$DATE.sql
# 保留最近 7 天的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
SCRIPT

chmod +x backup.sh
# 添加定时任务（每天凌晨 2 点）
echo "0 2 * * * /opt/geoai-platform/backup.sh" | crontab -
```

## 六、故障排查

### 数据库连接失败
```bash
# 检查 PostgreSQL 是否就绪
docker compose logs postgres
# 重启数据库
docker compose restart postgres
```

### API 服务无法启动
```bash
# 查看详细错误日志
docker compose logs backend
# 检查环境变量
docker compose exec backend env | grep DATABASE_URL
```

### 前端页面 404
```bash
# 重新构建前端
docker compose build frontend
docker compose up -d frontend
```

## 七、安全建议

1. **修改默认密码**：首次登录后立即修改 admin@geoai.com 的密码
2. **配置 HTTPS**：生产环境建议配置 SSL 证书（Let's Encrypt 免费）
3. **防火墙规则**：仅开放 80/443 端口，5432/8001 等内部端口绑定 127.0.0.1
4. **定期更新**：定期更新 Docker 镜像和依赖包
5. **JWT 密钥**：生产环境务必使用强随机密钥

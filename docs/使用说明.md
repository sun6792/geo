# GEO AI 智能体运营系统 — 使用说明

## 一、系统概述

GEO AI 智能体运营系统是一套企业级 GEO（生成式引擎优化）全域智能体平台，核心采用「五智能体自迭代闭环」架构，实现从知识库搭建 → 短板诊断 → AI 创作 → 人工双审 → 分层发布 → 周度复盘的完整业务闭环。

## 二、业务流程 SOP

### 标准操作流程

```
新建客户 → 搭建三层知识库 → 发起探测诊断 → AI 生成内容
    → 内部初审 → 客户终审 → 分层发布 → 效果录入 → 周度复盘
```

### 硬约束规则

1. **知识库前置**：每个客户必须先搭建知识库，才能启动内容创作
2. **人工双审**：AI 生成的所有稿件，必须经过「内部初审→客户终审」两道审核
3. **信息唯一真值**：所有内容的企业信息、产品参数，必须从知识库读取
4. **审核通过方可发布**：未通过双审的稿件，绝对禁止进入发布队列

## 三、各模块操作指南

### 3.1 客户管理（超级管理员）

1. 登录后进入「系统管理 → 客户管理」
2. 点击「新建客户」，填写客户基本信息
3. 系统自动为每个客户创建独立的数据空间

### 3.2 知识库管理

**三层资产体系：**
- **基础资产层**（唯一真值）：企业工商信息、资质证书、产品参数、联系方式
- **营销资产层**：行业关键词、用户搜索痛点、客户案例、差异化优势话术
- **多模态资产层**：产品图片、项目案例、技术白皮书、短视频素材

**操作步骤：**
1. 进入「知识库管理」
2. 先创建分类目录（可选）
3. 点击「新建资产」，选择资产类型、填写内容
4. 保存后系统自动进行向量化处理，支持语义检索

### 3.3 内容创作

**操作步骤：**
1. 进入「内容创作」
2. 点击「新建创作任务」，填写创作需求
3. **必须选择知识库来源资产**（系统强制校验）
4. 提交后触发 AI 自动生成
5. 生成完成后，可预览稿件、手动编辑或重新生成

**生成内容类型：**
- 通用深度主稿（权威版）
- 各模型适配版（豆包案例版、文心专业版、千问商业版、DeepSeek 技术版等）
- 三位一体衍生版（GEO 问答版、SEO 网页版、短视频图文版）

### 3.4 内容审核

**内部初审：**
1. 进入「内容审核 → 待审列表」
2. 点击稿件进入审核详情页
3. 逐项检查审核清单（事实准确性、合规性、信息一致性、内容质量、SEO 友好度）
4. 支持内联评论：选中稿件文本，添加针对性意见
5. 选择「通过」「驳回」或「需修改」

**客户终审：**
1. 内部审核通过后，点击「推送客户审核」
2. 输入客户邮箱和姓名
3. 系统生成匿名预览链接，发送给客户
4. 客户通过链接查看稿件并给出审核意见
5. 客户通过后，稿件锁定，进入发布队列

### 3.5 发布管理

**三级渠道矩阵：**
- **一级渠道**：央媒/省媒、行业协会、百科、企业官网（通用高权重）
- **平台专属渠道**：今日头条/百家号/阿里云社区/微信公众号 等各平台生态
- **二级渠道**：行业垂直媒体、B2B 平台、专业论坛（交叉信源佐证）

**操作步骤：**
1. 进入「发布管理 → 渠道配置」，配置发布渠道
2. 进入「发布管理」，选择已审核通过的稿件
3. 选择目标渠道，设置发布时间
4. 执行发布（支持 API 自动发布 + 手动录入结果）
5. 发布完成后，手动录入各渠道效果数据

### 3.6 账号管理

**角色权限体系：**

| 角色 | 权限范围 |
|------|---------|
| 超级管理员 | 平台全权限，可管理所有客户 |
| 管理员 | 租户内全权限 |
| 编辑员 | 知识库管理 + 内容创作 |
| 审核员 | 内容审核 + 查看 |
| 观察员 | 只读查看 |

**操作：**
- 进入「系统管理 → 用户管理」，创建/管理用户
- 进入「系统管理 → 角色管理」，配置自定义角色和权限

### 3.7 数据看板

- 知识库资产统计
- 内容生产流水线状态
- 待审核稿件数量
- 本周发布统计
- 近 30 天活动记录

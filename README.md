# GEO AI 智能体运营系统

企业级 GEO（生成式引擎优化）全域智能体平台，基于「五智能体自迭代闭环」架构，实现从知识库搭建、短板诊断、AI 创作、人工双审、分层发布到周度复盘的全自动飞轮闭环。

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue 3 + Element Plus + TypeScript | Vue 3.5 |
| 后端 | Python + FastAPI (async) | Python 3.10+ |
| 数据库 | PostgreSQL 15 + Chroma (向量库) | PG 15 |
| 任务调度 | APScheduler | 3.10 |
| 部署 | Docker + Docker Compose + Nginx | — |

## 快速开始

### 本地开发

**前置条件**: Python 3.10+, Node.js 20+, Docker Desktop

```bash
# 1. 启动数据库
docker compose up -d postgres chroma

# 2. 后端
cd backend
cp .env.example .env    # 编辑配置
pip install -r requirements/dev.txt
uvicorn app.main:app --reload --port 8000

# 3. 前端
cd frontend
npm install
npm run dev              # http://localhost:5173
```

### Docker 一键部署

```bash
# 配置环境变量
cp backend/.env.example backend/.env
# 编辑 .env 和项目根目录 .env

# 一键启动
docker compose up -d --build

# 访问 http://localhost
# 默认账号: admin@geoai.com / admin123
```
